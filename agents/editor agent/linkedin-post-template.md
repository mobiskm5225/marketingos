# LinkedIn Post — Narrative Structure

## When to use

For any LinkedIn post built for thought-leadership positioning, practitioner credibility, or personal-brand content — the primary deliverable of the Li Agent, run per-profile (Decision 4, Architecture V2.0: one profile per API call, never blended). Fits B2B/SaaS founders, operators and marketers writing to build authority rather than to sell directly. Not for company-page announcements, product launches, or paid promotion copy — those need a different structural template (flagged as a future build if volume justifies it).

## Structure

The core shape is **Moment → People → Meaning → Open Door**. Four movements, no fixed word count per movement — total post 150–210 words.

1. **Moment** (required) — Open on a single concrete instant: a specific conversation, a specific failure, a specific number. Not a category ("marketing is changing") — an instance ("a client asked me why their blog traffic doubled and conversions didn't move"). This is the hook. First two lines must work standalone before "see more" truncates the rest (~200 characters).
2. **People** (required) — Name who was involved, in role if not by name ("a client", "my content lead", "Ratnam"). The moment needs a human in it or it reads as a thought experiment rather than something that happened.
3. **Meaning** (required) — The single idea the moment illustrates. One idea, stated plainly, ideally with the rhetorical contrast pattern ("You're publishing. You're not compounding."). This is the paragraph a reader screenshots. Resist the urge to add a second idea — one post, one meaning.
4. **Open Door** (required) — Close on a question or an incomplete thought that invites a specific kind of comment, not "thoughts?". A P.S. line is the profile's signature closer where the voice doc specifies one.

**Optional/droppable modules:**
- A short numbered or bulleted breakdown *inside* the Meaning movement, when the idea has 2–3 concrete components — droppable for anything that resolves in a single sentence.
- A data point or statistic, when one exists and is sourced — strengthens Meaning but is not mandatory; do not force a number into a post that doesn't need one.
- Hashtags — 3–5 maximum, appended after the Open Door, never inline.

## Copy rules (from source)

- Short declarative sentences and parallel fragments over compound sentences.
- Rhetorical contrast as the primary device for stating Meaning.
- No filler words, no hedging language ("might", "could potentially", "in some ways").
- First-person, candid, grounded in something that actually happened — not a hypothetical dressed as an anecdote.
- Paragraphs 1–2 lines maximum, a line break every 1–2 sentences. No block paragraphs — this is what makes 150–210 words read as 30+ seconds of dwell time rather than a wall of text, and it's the majority-mobile-reader requirement (60%+ of LinkedIn sessions).
- 0–2 emojis total, used as visual anchors, never as decoration on every line.
- No external link in the post body. If a resource needs linking, it goes in the first comment — added at publish time or shortly after, not edited into the body later (an edited-in link within the first hour can suppress reach).
- Thematic focus over self-promotion: avoid naming personal tools, workflows or products unless the tool itself is the Moment. A broader, audience-relevant frame outperforms a tools-and-workflow post.
- Every profile using this template supplies its own voice doc (tone attributes, banned/approved terms, signature closer, hashtag set). The structure here is the skeleton; the voice doc is what makes it sound like a specific person, not an interchangeable one. **Never blend two profiles' voice docs on one draft.**

## Editing checklist before publishing

- [ ] First two lines work standalone, before "see more" truncates — no dependency on what follows
- [ ] Every paragraph is 1–2 lines; no block of text longer than that
- [ ] The Moment is a specific instance (a number, a name, a dated event) — not a category or a generalisation. This is the single biggest tell of AI-generated content: "every sentence is true of any company in any industry at any moment." If the Moment could belong to any company, it isn't specific enough yet.
- [ ] 0–2 emojis, used as anchors not decoration
- [ ] No external link in the body; if one belongs in the first comment, add it at publish time
- [ ] Hashtags (3–5) at the end only, never inline
- [ ] Previewed on mobile — this is where most readers will actually see it
- [ ] Read the Meaning line in isolation: does it hold up as a screenshot-able idea, or is it a restated truism?
