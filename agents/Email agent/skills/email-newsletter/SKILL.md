# Newsletter — Editorial / Insight Format

Source of truth: [Newsletter — Editorial / Insight Format](https://app.notion.com/p/3cb892c0700f81d6ab55fa4e2827ad27) in Reachify's Email Templates database (Format Key: `newsletter_editorial_format`). Cross-cutting technique reference: [Email Copywriting Fundamentals](https://app.notion.com/p/3cb892c0700f81e19b8cd74dd43f6c78). If this file and Notion disagree, Notion wins — re-export this file.

## When to use

Use this shell for a recurring, editorial-style newsletter whose job is to build authority and retain a subscriber relationship — not a promotional blast or a transactional sequence. Fits weekly/monthly insight, advice, or curated-content newsletters. Not for onboarding flows (use `email-onboarding-nurture-sequence`) or one-off prospecting (use `email-cold-outreach-sequence`).

## Before drafting, gather

- Newsletter name + one-line positioning/voice description
- This issue's hook/question/observation for the intro
- Main body format decision: deep-dive / Q&A / categorized listicle
- Section headers and content items for the main body
- Secondary/recurring module: keep, drop, or define new (must be sustainable every issue — don't propose a one-off recurring block)
- Sponsor/ad block: yes/no, and placement if yes (not part of the base benchmark structure — add only if this newsletter is monetized this way)
- Closing growth ask (single action: subscribe / share / refer)
- Sign-off name and reply-to/comments setup
- Client's brand voice/positioning (pull from the client's Brand KB if one exists)

If any of these are missing, ask before drafting.

## Structure

1. **Header / masthead.** Publication name, subscribe/sign-in options, consistent visual identity across issues.
2. **Title + subtitle.** Title states the issue's topic or question plainly; subtitle adds one line of framing or a hook. Author byline and date sit alongside.
3. **Intro hook.** Opens in first-person, direct address — a real question, observation, or reason this issue exists. Sets the frame before the body starts; 2–5 sentences, conversational register, not a formal abstract.
4. **Main body.** Organized either as a single deep-dive with subheadings, a Q&A (reader questions answered in sequence), or a categorized listicle (emoji + label headers grouping related items). Within the body: numbered lists for sequential advice, bullet lists for parallel items, bold text for section headers and key terms, embedded images/charts/GIFs where they clarify a point, hyperlinks to sources and related past issues throughout.
5. **Secondary/recurring module [OPTIONAL].** A consistent recurring block distinct from the main body — e.g. curated resource links, job listings, a reader-submitted item. Include only if the newsletter commits to running it every issue.
6. **Closing.** Personal sign-off (name, not just "the team"), one clear growth ask (share/subscribe/refer — pick one, not all three every issue), and space for reader comments/replies.

*Optional compression for a single-resource value-drop issue* (announcing one template/tool/asset rather than a multi-item roundup): Alex Hormozi's 3-step "Email SOP" works as a lightweight alternate structure — "I made this for you" → what it is / how it helps (one line) → how to get it (single link/CTA). Use sparingly — the multi-section format above stays the default for regular issues.

## Copy rules

- Write in first person, direct address ("you") — the authority comes from a real voice, not an institutional tone.
- Bold text marks section headers and key terms for skimmability; don't rely on paragraph density alone.
- Numbered lists carry attribution when featuring others' work or examples (name + company/context per item).
- Hyperlink generously — to sources, to past issues, to referenced tools.
- One clear ask per issue for growth actions; stacking multiple asks (subscribe + share + buy + refer) dilutes all of them.
- Favour scannability over exhaustive coverage.
- Subject-line technique to consider: Matt Gray's curiosity-driven, plain-text personal-note style (a specific tease, not a vague headline) — from the Email Copywriting Fundamentals doc.

## Output format

Return: subject line (1 primary option, tied to the issue's hook), full issue body in the chosen main-body format, and the closing CTA used. Flag if the Hormozi value-drop compression was used and why.
