# Feature Page — Copy + Layout

**Source:** DrDroid (drdroid.io), YC W23. Structure and technique only — no copy is reused verbatim from DrDroid. DrDroid had the cleanest technical SEO hygiene of the 10 audited YC SaaS sites.

## When to use

Use for an individual product, feature, or module page — not the full homepage. Best fit when the buyer is technical or specialist (the copy register here runs denser than the Landing Page template).

## Structure

1. **Credibility badge** directly above the H1 — funding, award, certification, or client-count marker.
2. **Hero** — H1 (capability-led headline) → subhead → primary CTA + secondary link.
3. **3-column categorized grid** immediately under the hero — each column is its own labeled stage or category, with 2–3 mini feature cards underneath.
4. **Repeating deep-dive blocks** — small uppercase eyebrow → bold 3-line H2 → supporting paragraph, paired with a live product visual/mockup on the opposite side. Alternate left/right per block down the page.

Optionally pull in `reachify-social-proof-stack` as a module between the grid and the deep-dive blocks if the client has strong quantified testimonials for this specific feature.

## Copy rules (from benchmark)

- Confident domain jargon is fine here — DrDroid's copy runs at grade 10.2, denser than the landing-page target, and that's appropriate for a specialist buyer (SRE/DevOps in their case). Match density to the actual reader, don't default to grade 10 for a general audience.
- Every deep-dive block earns its place only if it pairs a real capability with a real visual — don't stretch this pattern to cover a feature with nothing to show.

## Fields to fill per client

- [ ] Credibility badge text
- [ ] H1 + subhead + CTA labels
- [ ] 3 stage/category labels, each with 2–3 mini features
- [ ] N deep-dive blocks: eyebrow + headline + paragraph + visual, per major capability

## Technical checklist before publishing

- Exactly one H1
- 100% image alt-text coverage
- JSON-LD structured data + canonical tag present
- DrDroid hit all four of these — it's the gold-standard reference for this checklist across the 10 sites audited
