# Social Proof Stack — Layered Trust

**Source:** Clueso (clueso.io), YC W23. Structure and technique only — no copy is reused verbatim from Clueso. Clueso layered rating badge + logo wall + quote-as-headline more effectively than any other site in the 10 audited.

## When to use

Use embedded within a Landing Page or Feature Page, or as its own dedicated customers/proof page. Pulled in as a module by `reachify-landing-page`, `reachify-feature-page`, and `reachify-bofu-objection-competitor-comparison`.

## Structure

1. **Rating badge inline in the hero** — review-platform stars + score + platform name (e.g. G2, Capterra), placed in the hero itself, not lower on the page.
2. **Logo wall** — dense, uniform grid of client logos: same size, greyscale, no visual hierarchy between clients. Signals breadth fast.
3. **Testimonial-as-headline** — the single best customer quote, reset in large display type as if it were a section headline (not a quote box).
4. **Attribution card** below the quote — small photo + name + title + company.

## Copy rules (from benchmark)

- Pick ONE testimonial line to headline. Don't dilute the moment with multiple quotes stacked together — that's what the logo wall is for.
- Stat-specific praise beats generic praise: "20x faster" earns more trust than "great tool." Screen every candidate quote for a concrete number or outcome before choosing it.

## Fields to fill per client

- [ ] Rating score + review platform name
- [ ] Client logo list (aim for a full grid row, not 2–3 logos)
- [ ] Winning testimonial quote (with a concrete stat or outcome)
- [ ] Attribution: name, title, company, photo
