# Lean Hero / Benefit Copy

**Source:** Cone (getcone.io), YC S22. Structure and technique only — no copy is reused verbatim from Cone. Cone was the fastest, leanest page of the 10 audited YC SaaS sites.

## When to use

Use for any hero section where the brief calls for speed and minimalism — especially a multi-product or multi-module platform that needs to give visitors a simple entry choice fast.

## Structure

1. **H1** — short, 2–3 words, lowercase-style tone.
2. **Subhead** — one plain-English line.
3. **Rating badge** directly under the subhead, before any CTA.
4. **Two-card product/module selector** (if the client has more than one product) — name + one-line description per card, standing in for a navigation decision.
5. **Icon + label feature-chip row** beneath the selector, previewing the feature set before the visitor scrolls.
6. **Dual CTA row** — primary + secondary action.

## Copy rules (from benchmark)

- No jargon, no stacked clauses — Cone's whole hero reads at grade 9 despite being B2B software for accountants.
- This is also our technical-performance benchmark: pair this copy pattern with the technical checklist below rather than copying layout alone.

## Fields to fill per client

- [ ] H1 (2–3 words)
- [ ] Subhead (1 line)
- [ ] Rating score + platform
- [ ] Module/product names + 1-line descriptions (if multi-product)
- [ ] 3–4 feature chips (icon + label)
- [ ] Primary + secondary CTA labels

## Technical checklist before publishing

- Target under 150 KB page weight, under 1.5s full load, under 200ms TTFB
- Exactly one H1, full alt-text coverage
- Cone hit all of the above (102 KB / 1.37s / 113ms TTFB) — the performance ceiling every other template should be checked against
