# FAQ Block — Objection Handling

**Source:** Peoplebox.ai, YC S22. Structure and technique only — no copy is reused verbatim from Peoplebox.ai. Peoplebox had the deepest FAQ (17 questions) of the 10 audited YC SaaS sites.

## When to use

Use as a standalone objection-handling section, embedded inside a Landing Page, Feature Page, or pricing page. Also works as its own dedicated FAQ page. Pulled in as a module by `reachify-landing-page`, `reachify-tofu-educational`, and `reachify-mofu-comparison-buyers-guide`.

## Structure

1. **H2, centered** — "Frequently Asked Questions" (or client's phrasing).
2. **Q1 — pre-expanded** with a full answer (up to 2 short paragraphs). This should be the single biggest objection a prospect has, answered without requiring a click.
3. **Q2–Q4 — collapsed**, plain "+" icon to expand.
4. **"View more" control** below the first 3–4 questions, revealing the rest of the list (aim for 8–17 total questions).

## Copy rules (from benchmark)

- Order questions by real buyer urgency, not alphabetically or by internal team logic. Lead with "does this replace what I already use"-style objections before pricing or security questions.
- Cap every answer at 2 short paragraphs. Long enough to actually resolve the objection, short enough that it doesn't read as a wall of text.
