# MOFU Blog — Comparison / Buyer's Guide

**Source:** Secureframe Blog — "SOC 2 vs ISO 27001: What's the Difference and Which Standard Do You Need?" (secureframe.com/blog/soc-2-vs-iso-27001). Structure and technique only, no copy reused verbatim.

## When to use

Middle-of-funnel post for a reader who understands the problem and is now actively comparing two named options (frameworks, methodologies, tool categories) or evaluating a single category with no fixed second option. Flexible enough to cover both: drop the "Option B" module for a single-category buyer's guide.

## Structure

1. **Headline** — "[A] vs [B]: What's the Difference and Which Should You Choose?" (two-option) or "How to Choose a [Category] Tool" (single-category).
2. **Opening hook** — frame the choice as a real business dilemma the reader is facing right now ("many fast-growing companies face this exact question"), not an academic comparison.
3. **What is [A]? / What is [B]?** — skip for single-category guides; replace with "What to look for in a [category] tool."
4. **[OPTIONAL] Similarities** — include only when comparing two genuinely comparable options.
5. **Differences** — broken into a comparison table across concrete dimensions (cost, scope, timeline, flexibility, audit/process burden, etc.). This table is the anchor visual of the format.
6. **Which is right for you?** — a short set of self-diagnostic questions (5–8) the reader answers to self-select an option.
7. **Where [product] fits** — a proportionate, honest section on how the client's product/approach relates to the decision. Not a hard pitch.
8. **FAQ** — pull in the `reachify-faq-block` template.

## Copy rules (from benchmark)

- The comparison table is mandatory — concrete, checkable dimensions, not vague adjectives.
- Acknowledge real trade-offs honestly. This stage's credibility is what earns the BOFU click later — an obviously biased comparison burns that trust.
- CTA sits after the comparison table and again at the close: "request a demo" / "see how [product] handles this" — medium strength, not aggressive.

## Fields to fill per article
